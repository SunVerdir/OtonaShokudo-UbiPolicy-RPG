# ゲーム設計メモ

第七巻「多次元経営と人生ゲーム」の記述を、学習用の仕組みに落とした対応表です。ここに記す資源量・カード効果・指標はすべてゲーム内の仮定であり、現実の政策効果を表しません。

| 第七巻の記述 | このゲームでの仕組み |
| --- | --- |
| 舞台は、食材も人手も予算も限られた架空の「大人食堂ワールド」 | 資源は4つ（食材・予算・人手・電力通信）。初期値も少なく、毎ラウンドの回復も少なめ |
| プレイヤーは住民・生産者・運営者・行政・技術者（政策FDE）の役を交代 | ラウンドごとに「今回の役」と視点の問いが表示される。複数人なら担当者も交代 |
| イベントカードで起きる想定外に挑む | 9種のイベント。第1ラウンドは必ず「世界大恐慌」。残りはシャッフル（`--seed`で再現可） |
| サイコロで政策を決めず、選択理由と見落としを振り返る | 政策は番号で選び、理由は任意。最後に見落とされた声と次の検証課題を表示 |
| 点数を競うより、次の検証課題を持ち帰る | 「有り難う！」はタグ対応の記録数から味見省略回数を差し引く仮想指標。勝者やランキングは設けず、実際の感謝・満足度・同意・政策効果とは扱わない |
| 行動カードの意味を初見でもつかめるようにする | 各カードに対応タグを表示。`◇`は今回の困りごとタグとの重なりを示す目印で、おすすめや解決保証ではない |
| 味見だけは、必ずシェフが | AI提案を含む行動は人が「味見」（人手-1）できる。省略時の指標減少はゲーム内ルール上の調整のみ |
| 異論、パス、途中離脱の選択肢 | `o`で異論、`p`で担当者名・理由をレポートに残さずパス、`q`で途中離脱。パス時もゲーム進行上の役割・イベント・結果は記録される |
| 三つの記憶 | ゲームの最後に、一言ずつ書ける（任意）。本名や個人情報は入力しない |
| 同じ条件で違う選択を試す | ゲームごとのseedをレポートに表示し、同じ標準イベント順の再戦コマンドを出す。選択理由や異論はコマンドへ含めない |

第七巻草稿の一部には「有り難う！の数を競う」「優勝」とする案がありますが、この試作品では採用していません。「有り難う！」はゲーム内の仮想指標であり、現実の感謝や政策成果を表さないため、順位づけに使うと誤解を招くおそれがあります。本版は勝者やランキングを設けず、参加者が協力して見落とした声と検証課題を探す設計です。

## 初めての一周

1. イベントカードで、架空の出来事と現場の声を読む。
2. 行動カードを見て、今回の声とタグが重なるものを最大2枚選ぶ。何も選ばず見送ってもよい。
3. AIの提案カードでは、人が内容を確認するか選ぶ。理由の入力も任意。
4. 結果と、まだ対応できていない声を見て、次に検証したい問いを持ち帰る。

短く試したい場合は `otona-shokudo-rpg --quick` で3ラウンドを遊べます。`--seed 7` のようにseedを指定するか、終了後に表示される再戦コマンドを使うと、同じ標準イベント順で選択を変えて試せます。`--rounds N` を指定した場合は、`--quick`より明示したラウンド数を優先します。

## 60分ワークショップの進め方（案）

- 5分：ゲーム案の注意書きと、異論・パス・離脱の権利を読み合わせる。
- 30分：3〜5人で遊ぶ（`--players ゆい,そら,はる`）。声に出すことも理由を書くことも任意。本名ではなくニックネームを使う。
- 15分：振り返りレポートを見ながら、見落としていた声と「次の検証課題」を話し合う。
- 10分：「ルールを一つ書き換えるなら？」を出し合い、Issue（ルール提案）にする。
